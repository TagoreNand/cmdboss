"""
CMDBoss Example Hook — Server
===============================
This hook fires asynchronously on CRUD operations for the 'server' collection.

Hooks are Python callables that receive the affected document as a dict.
They run in a background thread and must not block the main request thread.

Supported events: on_create, on_read, on_update, on_delete
"""
